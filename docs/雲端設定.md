# 雲端會員空間設定（Neon · 單人）

讓**持股、交易紀錄、訊號日誌與所有設定**永久保存並自動同步——重整、重新部署、換手機都還在。
未設定時 App 行為與原本完全一致（雲端區塊不顯示），所以**設定前可照常使用**。

---

## 一、建立 Neon 資料庫（約 3 分鐘，免費）

1. 到 <https://neon.com> 註冊 → **Create project**（區域選 **Singapore / ap-southeast** 離台灣近）。
2. 建好後，在 **Dashboard → Connection string** 複製連線字串，長這樣：
   ```
   postgresql://user:password@ep-xxxx-xxxx.ap-southeast-1.aws.neon.tech/dbname?sslmode=require
   ```
   （要含 `?sslmode=require`；用 **Pooled connection** 那條更穩。）

> 不用自己建表——App 第一次寫入時會自動建好 `tw_kv` 表。

---

## 二、把密鑰貼進 Streamlit Cloud（只能你本人做）

1. 到你的 App 頁 → 右上 **Manage app → Settings → Secrets**。
2. 貼上這三行（換成你的值）：
   ```toml
   DATABASE_URL = "postgresql://user:password@ep-xxxx.ap-southeast-1.aws.neon.tech/dbname?sslmode=require"
   APP_PASSCODE = "自己設一組密碼"
   ```
3. **Save** → App 會自動重啟。

---

## 三、使用

1. 重啟後，到 **「設定」頁的「雲端帳號」** → 輸入你設的 `APP_PASSCODE` → **登入**。
2. 之後全部自動，不用按「存到雲端」：

| 資料 | 什麼時候上傳 | 換裝置 |
|---|---|---|
| 持股 | 在持股表編輯、或在交易計畫卡按「我已買進」之後 | 登入就載回 |
| 交易紀錄 | 記入賣出、編輯、匯入之後 | 登入就載回 |
| 訊號日誌 | 每次掃描有新的進場訊號之後 | 登入就載回 |
| 設定 | 總資金、月目標、單筆風險、選股條件、權重、成本、漲跌顏色等改了之後 | 登入就套用 |

- **只傳有變的**：內容沒改不會寫入；一條連線重複使用，不會每次存檔都等資料庫醒來。
- **頁首會顯示狀態**：「已同步 08:15」、「同步中斷，稍後自動重試」（資料先留在這個分頁，連上後自動補傳）。
- **另一台裝置改過**：每次換頁最多每 45 秒檢查一次，這台沒改的話會自動更新並跳出提示；「設定」頁的「立即檢查更新」可以馬上檢查。
- **兩台同時改**（例如手機改了持股、電腦也改了）：交易紀錄與訊號日誌會自動合併；持股與設定會在頁面最上方問你要保留哪一份，不會默默蓋掉。
- **登入前就有的資料**：雲端是空的就直接上傳；雲端也有、內容不同時，交易紀錄與日誌合併，持股請你選。
- **登出**：這個分頁裡的持股、交易紀錄、日誌與財務設定會一起清掉（雲端的不受影響），共用電腦時下一個人看不到。

## 常見問題

- **沒設定會怎樣？** 持股、交易紀錄、訊號日誌只存在這個瀏覽器分頁（重整會清空，可用匯出備份）。不會寫進伺服器上的檔案：公開部署時伺服器檔案是所有訪客共用的。
- **安全嗎？** 連線走 SSL；只有知道 `APP_PASSCODE` 的人能登入讀寫。建議密碼別太簡單。
- **想多人共用？** 目前是單人（owner 固定）。要開放多人註冊再告知，可升級為每人獨立帳號（Auth + 權限）。
- **本機跑（非雲端）？** 在專案根目錄建 `.streamlit/secrets.toml` 貼上同內容（已在 .gitignore，**勿 commit 進 git**）。本機有 PostgreSQL 也可以用 `postgresql://user@127.0.0.1:5432/db`。
- **資料存在哪？** 一張表 `tw_kv(owner, key, value jsonb, updated_at)`，key 為 holdings / trades / journal / prefs。`updated_at` 同時當版本號，用來發現另一台裝置的修改。
