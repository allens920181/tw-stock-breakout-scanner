# 台股強勢突破交易清單（換手率版）

掃描 `stock_list.xlsx` 中的股票，依 MA / KD / MACD / 突破 / 量能 / 換手率 8 項條件評分，輸出 Excel 報告。

## 特色
- 自動判斷上市 (.TW) / 上櫃 (.TWO)
- 批次下載 + 平行抓股數 + Parquet 本地快取（同日不重抓）
- 評分分級：強勢候選 / 觀察 / 偏弱觀察 / 不符合
- 自動計算進場價、停損價、目標價、RR 比

## 安裝

```bash
uv sync
```

## 使用

1. 建立 `stock_list.xlsx`，欄位：`股票代號`、`公司名稱`
2. 執行：

```bash
uv run python 台股強勢突破交易清單_換手率版_v3.py
```

3. 報告輸出為 `台股全部分析報告_自動判斷市場_YYYYMMDD_HHMMSS.xlsx`

## 策略條件（8 項評分）
| 條件 | 說明 |
| --- | --- |
| MA 多頭排列 | MA5 > MA20 > MA60 |
| 站上 MA20 | Close > MA20 |
| KD 強勢 | K > D 且 K > 70 |
| MACD 多方 | OSC > 0 |
| 突破 20 日高 | Close > 近 20 日最高 |
| 量能放大 | Volume > 20 日均量 × 1.2 |
| 換手率 > 1% | 當日換手率 |
| 換手率高於均值 | 當日換手率 > 20 日平均換手率 |

≥6 強勢候選、≥5 觀察、≥4 偏弱觀察。
